# Impeccable usage (BSS Dispatch)

Installed project-scoped for Cursor. After reload, Agent commands include `/impeccable …`.

## Suggested sequence for this UI

1. `/impeccable onboard` — empty / first-run lock overlay
2. `/impeccable harden` — upload errors, simulate failures
3. `/impeccable animate` — unlock timeline + pipeline theater
4. `/impeccable polish` — final visual pass
5. `/impeccable audit` — before demo

Optional CLI: `npx impeccable detect web/src`
